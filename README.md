# 课程代码整理

这个仓库用于保存我的课程作业代码和一些练习文件，方便记录修改历史和同步到 GitHub。

## 目录说明

| 目录 | 说明 |
| --- | --- |
| `C Programming Language` | C 语言程序设计课程的作业代码 |
| `Data Structures` | 数据结构课程作业、图结构实现、NumPy 数据处理和配套教学数据 |
| `Introduction to AI` | 人工智能专业导论实验代码，按 `lab1`、`lab2`、`lab3`、`lab4` 分目录 |
| `Micro-specialization` | 微专业课程相关代码和资料（已移除） |
| `Python/Python Programming Practice` | Python 程序设计实践课程代码 |
| `Python/Python Programming` | Python 程序设计课程代码 |
| `Python/python-final-review` | Python 期末复习静态页面与题库 |

## 其他内容

除上面列出的课程目录外，仓库中其他内容主要是测试文件、临时练习或其他无关文件。

## 备注

部分本地文件不会上传到仓库，例如虚拟环境、系统缓存、压缩包、编译产物，以及包含个人 API key 的 notebook。

课程程序需要的教学输入数据随代码保存；可重新生成的 `Data Structures/2026-11-12/results/results.npz` 仅保留在本地，运行对应程序即可生成。
