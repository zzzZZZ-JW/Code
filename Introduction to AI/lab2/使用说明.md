## 日常使用

1. 双击 `启动Neo4j.command`，等待浏览器打开。
2. 双击 `查看登录信息.command`，在终端查看实验专用密码；使用用户名 neo4j 登录。初始密码已设置，不需要再使用默认密码 neo4j。
3. 在 Neo4j Browser 输入 `RETURN 1 AS ok;` 可以检查查询。
4. 双击 `验证环境.command` 可验证 Java、Python 依赖、网页、数据库认证、中文 CSV 和节点关系增删改查。
5. 实验结束后，双击 `停止Neo4j.command`。未配置开机自动启动。

数据库运行于本机，不在 Neo4j Desktop 内管理。使用上述入口启停；避免另一个实例同时占用 7474 和 7687。

Python 连接代码：

```python

import json
from py2neo import Graph

base = Path.home() / '.local/share/ai-intro-lab2'
config = json.loads((base / 'connection.json').read_text())
graph = Graph(config['uri'], auth=(config['user'], config['password']))
print(graph.run('RETURN 1 AS ok').data())
```
